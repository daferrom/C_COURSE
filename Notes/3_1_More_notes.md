# C

Translation for Python C to C

- C is the Mother tongue of modern languages
- Python was deeply influenced by C.
- Python is written in C
- Python is Object oriented language Like JS
- Java is less object oriented language
- C is non oriented object language

- C is fast efficient Powerful:

- struct, pointers
- Manual memory management
- White Space is essential in Python and C

Python and C Similarites

- Arithmetic Operators: + - * / %
- Comparison Operators: == , !=, <>, <= the same
- Variable naming rules - letter/underscore + number/letters/underscores - also case matters
- While loops - also break and continue in loops.
- Constant similar except for strings and characters and booleans
- Both have int/ float , and char / byte
- C has no str,list , or dict
- Python has no struct or double

# Differences

- Boolean operators: and / not / or versus && ! ||
- C for loops are indeterminant (i.e no for ...in in C)
- C has no pre-defined True or False
- None and NUL are similar concepts but quite different
- Strings and character arrays are similar concepts but *Very* different
- C has no list, or dict
- Python has no struct - float in Python is a C double
